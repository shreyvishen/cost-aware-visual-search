Cost-aware visual search

A 4B vision model decides where to look in a high-resolution image. The reward charges milliseconds measured on the machine it ships to, not a token count. Same accuracy, 2.18× faster on device.

The reward

reward = correct ? (1 − λ · cost_ms) : 0 cost_ms = 1.411·vision_tokens + 13.198·decode_tokens + 101.79·zooms
No cost
λ = 0

Get it right, score 1. Get it wrong, score 0. Nothing else counts, so looking and thinking are free.

Cost-aware
λ = 5.85e−5

Same, minus what the episode costs in milliseconds. The three coefficients were measured on an M4 Max, not guessed.

The cost only applies if the answer is right. That matters: the model can never buy speed by being wrong, so the two runs stay comparable on accuracy by construction.

What looking buys

Same policy, same 96 V*Bench questions, zoom allowed vs. forbidden. V*Bench is 191 high-resolution photos (~2250×1500) where the thing being asked about covers roughly 0.06% of the frame — small enough that a downscaled view genuinely cannot answer it.
